KleeAPI 新版启动说明

Windows x64 便携发布 ZIP：完整解压后直接双击 Start-Manager.cmd，用完双击 Stop-Manager.cmd。已内置运行时与页面，无需安装 Node、npm 或构建。不要在压缩包内直接运行。
源码版也可直接双击 Start；电脑已有可用 Node 和 npm 时，会自动准备缺少的依赖与页面。维护者可运行 npm run release:win 制作便携包，成品位于 output/releases/，不会包含本机账号、Key 或聊天记录。

1. 初次运行：直接双击 Start-Manager.cmd。自动检测已有 Node.js 22.12+；首次自动安装缺少的前端依赖并构建，后续不重复执行。找不到可用 Node 或自动准备失败时，按窗口提示安装完整 Node（包含 npm），或下载便携版。
2. 双击 Start-Manager.cmd，等待自动打开 http://127.0.0.1:18887/admin。
3. 关闭时双击 Stop-Manager.cmd；仅停止本目录管理器拥有的服务。
4. npm start 可在终端前台启动，npm run status 查看状态，npm stop 停止。
5. 日志：runtime/logs。端口配置：klee-config.json。Trae 回调端口18080若被占用，仅禁用新项目 Trae 官方网页登录，API和导入仍可用。
6. 源码不带便携 node.exe、前端编译产物和私有账号。此工作目录已有便携 Node，可供编译后的便携运行。
7. 首次真实启动会创建全新的私有账号存储与 API Key，没有迁移旧版账号；请自行登录或导入。

完整说明见 README.md。
