用户已授权完整重构，沿用 Vue 3、Element Plus 与本地 Node 服务，保留可莉主题及工作区现有未提交功能。

## 设计

深色石墨底色与薄荷绿操作色；固定平台切换和功能导航。默认进入总览，提供账号、签到、模型与 API 的快捷操作。密钥移入独立设置页，首次未配置时给出入口。移动端平台与功能导航仍可操作。可莉主题沿用本地素材、偏好存储和动效控制。
