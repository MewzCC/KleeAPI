**实现：** 沿用现有管理器，内置固定版本、校验过的 Node LTS 与 Qoder 官方组件；用文件白名单组装全新的发布目录，生成 ZIP 和 SHA-256。保持原有账号目录与停止服务的身份校验。

**范围：** 在当前工作区实施，保留已有业务改动。实现阶段未提交或上传；用户随后明确要求发布到 GitHub，因此发布阶段将同步与成品对应的源码、版本标签和干净发布附件。
